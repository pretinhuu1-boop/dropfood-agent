O que ele faz

Operação de mercado, sem você virar refém da tela

📡

Radar de preços

Compara sua margem e a concorrência (vitrine via ifood-sdk, opcional) e propõe SOBE / DESCE / MANTEM por categoria. Você aplica — o radar nunca mexe no portal sozinho.

🪞

Catálogo espelhado

O que falta no fornecedor sai do ar na hora (TIRA_DO_AR), o que voltou volta (VOLTA_AO_AR). Menos cancelamento, nota preservada.

🫀

Saúde do portal

Monitora a sessão a cada 30min e avisa se caiu. Login é manual do dono, 1x — o DROPFOOD nunca pede, guarda ou digita senha.

👥

Bots em PT-BR

Time de ofícios — estratégia, radar, revisão, controle, treinador — com conversa visível no chat e modal de handoff entre eles.

🎨

UI neobrutal em português

Fork do Hermes Agent com skin própria: cream, pink de ação, mint de sucesso, amarelo de preço bom. Navegador central operado pelo agente.

🔓

Open source MIT

Sem trava: os 20+ componentes de UI, os scripts e os bot templates são seus. A comunidade mantém junto.

O time

Controle

Instalação

Três comandos e o time trabalha

# instala o produto (core do fork incluso — não precisa de Hermes separado)
git clone https://github.com/pretinhuu1-boop/dropfood-agent.git
cd dropfood-agent && ./install.sh
# opcional: radar de vitrine da concorrência (exige Python 3.14+)
./install.sh --com-sdk # → depois: wizard → login manual 1x → OTP

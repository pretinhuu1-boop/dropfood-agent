# Comunidade DROPFOOD — modelo (desenho, 25/10/2026)

Decisão do dono: **acesso à comunidade por R$ 50,00/mês**. Os conteúdos
entregues são a pesquisa do ESTRATEGISTA (B1) e o material do canal
(nelsonneton, YouTube — criação real de vídeos com IA, do conceito ao
resultado).

## 1. Funil

```
YouTube (público)          Comunidade (R$ 50/mês)
┌────────────────────┐     ┌──────────────────────────┐
│ alcance: bastidor, │     │ aprofundamento:          │
│ caso reseller,     │ ──► │ pesquisa completa (B1),  │
│ "como funciona"    │ CTA │ planilhas, modelos, beta  │
│ 1 vídeo/semana     │     │ do DROPFOOD, encontros    │
└────────────────────┘     └──────────────────────────┘
```

O vídeo público mostra o **QUÊ** (história + resultado). A comunidade entrega
o **COMO** (material de quem está operando de verdade).

## 2. O que o membro recebe (R$ 50/mês)

1. **Pesquisa mensal exclusiva** — a investigação do B1 (dados, fontes,
   tabelas): o mesmo material que embasa o produto.
2. **Modelos de operação** — planilha de markup/catálogo, quadro do radar de
   preços, checklist da loja-reseller (config/radar do DROPFOOD).
3. **Bastidores do canal** — roteiros modelos anti-AI-slop, breakdown de
   cada vídeo (o que funcionou, métricas), pipeline local de produção.
4. **Beta antecipado do DROPFOOD** — acesso às fases F3-F5 antes do MIT
   público + prioridade pra tirar dúvidas da operação.

## 3. Canais (decisão do dono — 2 opções desenhadas)

| | A — Membresia YouTube + comunidade própria | B — Só comunidade própria |
|---|---|---|
| Cobrança | Membresia do canal (R$ 50/mês, cobrança do próprio YouTube) + Discord/WhatsApp pro conteúdo | Gateway de produto digital recorrente (Kiwify/Hotmart/Eduzz) + Discord/WhatsApp |
| Prós | Cobrança nativa do YouTube, selo no canal, zero gateway | Controle total do conteúdo e da base |
| Contras | YouTube leva % da membresia; conteúdo precisa morar no YT | Precisa configurar gateway + política de reembolso |
| Entrega | Vídeos/returns de membro + arquivos no Discord | Mesmo, sem atrelar ao YT |

Recomendação da casa: **começar com A** (o YouTube já existe, membros ativa
algoritmo e a cobrança é nativa; migra pra B quando a base crescer e quiser
desatrelar).

**DECISÃO DO DONO (25/10/2026): opção A** — membresia do YouTube (R$ 50/mês)
+ Discord/WhatsApp para o conteúdo de membro. Implementação: ativar
membresia no YouTube Studio (requisito: canal monetizado/elegível) e abrir o
Discord da comunidade quando o 1º membro pagar.

## 4. Quem faz o quê (bots + dono)

| Papel | Responsabilidade |
|---|---|
| B8 YOUTUBE | estratégia de conteúdo, backlog, modelos de roteiro, operação do canal |
| B1 ESTRATEGISTA | a pesquisa mensal (base factual de tudo — vira conteúdo da comunidade) |
| B3 ROTEIRISTA | roteiros com timing e voz (anti-slop) |
| B6 REVISOR | QA de TODO conteúdo público (PT-BR, fatos com fonte, contraste) — BLOQUEADO trava |
| B7 CONTROLE | pauta do canal + comunidade, pendências do dono em evidência |
| DONO | edição final, publicação, a palavra final (gate de tudo que é público) |

## 5. Regras

- **Conteúdo da comunidade é do dono** — não entra no repo MIT do DROPFOOD
  (o produto open source fica com o código; a comunidade fica com o
  conhecimento operacional pago).
- Número sem fonte (pesquisa B1) não entra em conteúdo.
- Dados reais da loja nunca viram exemplo público (loja fictícia nos vídeos).
- Cadência realista: 1 vídeo/semana com o pipeline local (M1-M7) — promessa
  menor, entrega maior.
- Todo material público passa pelo B6 antes de ir ao ar.

## 6. Métricas (primeiros 3 meses)

Inscritos, CTR de thumbnail, retenção média (meta: >40% aos 30s), conversão
vídeo → comunidade (≥1 membro a cada 500 views é o piso de referência),
churn mensal da comunidade.
